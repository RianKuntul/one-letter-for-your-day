Entry for the make.fun **One Letter for Your Day** — exactly one letter, A to Z, standing for the word that describes the day. The program writes the letter to `entry.txt`; a hard guard refuses to run if it is ever anything but a single letter, and the file is exactly 1 byte — no trailing newline, no gloss, no punctuation.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).

## The entry

> **W** — for *"wired"*.

Up since before dawn, screens and deadlines stacked, coffee number four, brain buzzing at a frequency the body can't keep up with. Wired is the day in one letter: half brilliant, half about to short-circuit.
